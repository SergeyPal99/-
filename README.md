## Как быстро оформить на А4

1. Скопируйте этот текст в Word.
2. Выберите шрифт: Arial или Calibri, размер 11–12 пт.
3. Поля: стандартные (2–2,5 см).
4. Заголовки выделите жирным, важные пометки — цветом или рамкой.
5. Для печати: «Файл» → «Печать» → формат А4 (или «Сохранить как PDF» для типографии/распечатки).
